Copia de Seguridad - CEPCI
Exportar / Importar backup completo de TODA la base de datos

Descargar respaldo completo

Haz clic en "Exportar respaldo completo" para descargar un archivo JSON que contiene ABSOLUTAMENTE TODO el sistema CEPCI: alumnos, maestros, materias, asesores, grupos, usuarios, movimientos de caja, sesiones de caja, imágenes de perfil (en base64), y todas las configuraciones globales. Este es un respaldo 100% completo del sistema.

Información importante: Este respaldo contiene ABSOLUTAMENTE TODOS los datos del sistema CEPCI incluyendo alumnos, maestros, materias, asesores, grupos, usuarios, caja (movimientos y sesiones), imágenes de perfil, y todas las configuraciones globales. Guarda el archivo en un lugar seguro (Documentos, USB, Google Drive, OneDrive, etc.). Para restaurarlo en otra PC, carga este archivo aquí en la sección "Importar respaldo". Este respaldo puede usarse para migrar el sistema completo a otra computadora.

Importar respaldo (restaurar sistema completo)

Si ya tienes un archivo de respaldo (.json) puedes importarlo aquí para restaurar COMPLETAMENTE el sistema. Esto reemplazará TODOS los datos actuales por los del backup (alumnos, maestros, materias, asesores, grupos, usuarios, caja completa, imágenes, configuraciones). Perfecto para migrar el sistema a otra PC o restaurar desde un respaldo anterior.
